# radio-system

Code for my Arduino project using the following components:
- A DS3231 for timekeeping
- An AHT20 for temperature/humidity
- A potentiometer for volume control
- A rotary encoder for tuning
- An OLED display
- An SI4703 for radio

A lot of my code might be commented out. The reason for this is that these are features that I chose not to keep, for simplicity. They do work fine. If you are trying to build a radio using any/all of these components, feel free to ask me anything.
